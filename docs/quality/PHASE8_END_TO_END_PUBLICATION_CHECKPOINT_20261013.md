## Safety and deployment

- `.env.example` introduces `PHASE8_REPORT_RELEASE_ENABLED=false` and `PHASE8_REPORT_RECIPIENT_ACCESS_ENABLED=false`. Both service gates reject live release or recipient read/ack without their independent server-side enablement; no silent rollout on DB migration or policy adoption. These must remain false pending positive full testing, explicit deployment review and privacy/operational sign-off.
- Older saved academic approval/reviewer status or private preview is **not publication**. One policy revision is **not publication**. One guardian attestation or receipt is **not broad access**.
- Historical release/receipt always stored and immutable; newest ordinal is the only eligible current version. Direct report-page browser print stores no static shareable server file.
- No GitHub Actions workflows started/rerun/edited; no PR opened (avoids workflow trigger), no merges, no production migrations, no staging deployment, no school/guardian data touched.
