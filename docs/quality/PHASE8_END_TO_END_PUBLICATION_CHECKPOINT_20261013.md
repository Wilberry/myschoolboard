School-row serialization establishes an immutable ordinal per school/session/term/class/subject, superseding—not modifying—older official releases.
5. New `ReportGuardianAcknowledgment`: independently authenticated currently linked PARENT explicitly acknowledges the exact current release and child. SQL rechecks current policy, newest ordinal, exact child/current same-class+session enrollment, guardian member+user ID, link and unrevoked status under school lock. Duplicate acknowledgments or history mutation are rejected.
6. Authenticated recipient GET takes **no child selector**, requires same-school active STUDENT/PARENT membership, active same-school pupil+exact class/session enrollment, unrevoked independently attested student or guardian relationship, newest release and still-current policy in final SQL, and returns only bounded student frozen identity, term/class/subject and composed official grade labels/percentages. Guardian-first student read additionally demands an immutable receipt by a guardian whose link and membership remain valid. No raw source packets, private answer keys, marks, another child's grades, unaudited edits or public report URL. School-specific printable subject list can be saved locally as PDF by the authenticated browser; it is not a school-hosted downloadable PDF artifact, rank, or confirmation of all subjects.

## Safety and deployment

- `.env.example` introduces `PHASE8_REPORT_RELEASE_ENABLED=false` and `PHASE8_REPORT_RECIPIENT_ACCESS_ENABLED=false`. Both service gates reject live release or recipient read/ack without their independent server-side enablement; no silent rollout on DB migration or policy adoption. These must remain false pending positive full testing, explicit deployment review and privacy/operational sign-off.
- Older saved academic approval/reviewer status or private preview is **not publication**. One policy revision is **not publication**. One guardian attestation or receipt is **not broad access**.
- Historical release/receipt always stored and immutable; newest ordinal is the only eligible current version. Direct report-page browser print stores no static shareable server file.
- No GitHub Actions workflows started/rerun/edited; no PR opened (avoids workflow trigger), no merges, no production migrations, no staging deployment, no school/guardian data touched.
