# Assignments and E-Library

## Scope

Assignments, student submissions when approved, and learning resources.

## Key requirements

- Students only access assignments intended for their class and release policy.
- The e-library separates approved physical-book catalog records from actual digital assets.
- Digital resources require access restrictions and file security controls.
- Copyright and licensing restrictions must be considered.

## Important design note

The product must not assume it can distribute copyrighted content without approval.
