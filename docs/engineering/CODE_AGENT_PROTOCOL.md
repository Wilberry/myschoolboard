# Code Agent Protocol

This file defines the required agent discipline for implementation work.

## Required practices

- Read the root AGENTS file and documentation index before making edits.
- Trace the work to a requirement ID and acceptance criterion.
- Keep changes small, coherent, and auditable.
- Verify the exact behavior with targeted tests.
- Update requirements, roadmap, and decision records when behavior changes.
- Never bypass authorization or data-integrity rules to satisfy a test.

## Prohibited behavior

- Silent requirement rewriting
- Removing tests to force a green result
- Destructive repo changes without explicit authorization
- Cross-tenant or permission bypass
- Claiming completed work without validation evidence
