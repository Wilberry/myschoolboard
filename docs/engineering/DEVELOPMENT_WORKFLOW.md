# Development Workflow

## Workflow rules

1. Read AGENTS.md and docs/README.md.
2. Review requirement IDs and acceptance criteria.
3. Inspect relevant code before editing.
4. Implement the minimal coherent change.
5. Add or update tests.
6. Run the relevant validation checks.
7. Update documentation if the behavior or architecture changes.
8. Record status in the roadmap and decision log.

## Current status

This workflow is the specification baseline for all future implementation.
